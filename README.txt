HOW TO PREVIEW ON IPHONE OR IPAD
1. Unzip the folder in the Files app.
2. Tap index.html. If the Files preview is limited, open it in a browser or upload through GitHub.

HOW TO UPDATE THROUGH GITHUB
1. Open your repository.
2. Remove the old index.html only after confirming you have this ZIP saved.
3. Upload index.html, styles.css, script.js, and the entire assets folder.
4. Commit the changes.
5. Cloudflare will rebuild automatically.
